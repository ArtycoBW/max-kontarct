## Что исправлено по результатам

- Убраны технические оговорки из интерфейса и README новых архивов; тексты входа, подготовки договора и проверки понятны пользователю.
- Необязательное согласие на статусные сообщения больше не блокирует вступление. Бот учитывает это согласие; запрошенный самим пользователем код подписи от него не зависит.
- При конфликте времени обновления согласование повторяется один раз только для полностью тех же условий. Новая версия или изменённое содержание автоматически не согласовываются.
- Для операций записи увеличено время ожидания ответа: клиент не обрывает ещё выполняющееся сохранение/подписание после короткого тайм-аута.
- Запросы изменения данных с посторонним Origin запрещены; провайдер `fake` для SMS запрещён в production ENV.
- В прикладных логах убраны параметры URL и сырые ошибки провайдеров/БД. Безопасный формат Nginx назначен внутри каждого virtual host, чтобы не дублировать стандартный access log. Проверочный маркер из query отсутствует в прикладном и access-журналах стенда.
- Nginx больше не обрезает допустимую загрузку на 12 МБ: лимит запроса 21 МиБ, прикладной лимит файла остаётся 20 МиБ.
- QR-блок в новом коротком PDF больше не переносится на отдельную почти пустую страницу.

SHA-256 каждого файла ZIP совпадает с manifest; личных документов в общем архиве нет. Снимки и тестовые файлы находятся в игнорируемом `test-results/`.

## Сервер и восстановление

На стенде сохранён запуск через systemd, отдельно испытан production Docker. При каждой выкладке проверены миграции, три службы и readiness PostgreSQL/Redis/S3. Прежние подписанные версии и артефакты не изменялись: публичная проверка существующего договора `МК-20260902-7A63BD68-V1` возвращает `VALID`, SHA-256 PDF остался `6f946863c1d40ff1b7e635394071a7ecfa7edf5531b15c672b1874ce4ad2d360`.

Backup восстановлен в отдельном тестовом контейнере: совпали 17 миграций, 2 пользователя, 7 сделок, 4 подписи, 4 артефакта и агрегаты хешей файлов/артефактов. Retention проверен на синтетических файлах: старая автоматически именованная копия удалена, ручная сохранена. Timer включён ежедневно на 03:20 UTC с задержкой до 10 минут; запуск service вручную успешен. Реальный backup хранится с правами 0600.

После проверок выделенный контейнер с браузерными базами и копией восстановления удалён вместе с его тестовым томом; SSH-туннель закрыт. Промежуточные сборки этого этапа очищены выборочно, исходники сохранены в коммитах, рабочий release и предыдущая версия для отката не удаляются.
