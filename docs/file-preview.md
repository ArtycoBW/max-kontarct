# Предпросмотр файлов

Единый просмотрщик используется в приложениях договора, обязательных документах, материалах и доказательствах, ручной проверке администратора и для подписанного PDF. Окно и кнопки — общие компоненты shadcn/ui проекта.

- JPEG, PNG, WebP: масштаб, сброс масштаба, поворот и прокрутка увеличенного изображения.
- PDF: постраничное отображение, предыдущая/следующая страница, масштаб и поворот. Отображается одна страница за раз, размер canvas ограничен для снижения расхода памяти.
- Список вложений: переключение файлов внутри окна, тип и размер, отдельное скачивание оригинала.
- Неподдерживаемый, повреждённый или защищённый паролем файл: объяснение и скачивание. При сетевой ошибке доступна повторная попытка.
- Доступ проверяет существующий серверный endpoint. Ошибки 401/403/404 не подменяются успешным просмотром. Личные документы не попадают в общий список договора.
- Содержимое загружается только после открытия, с credentials и cache:no-store. Изображения используют временные blob URL, которые освобождаются при закрытии/смене файла. Запросы отменяются, PDF worker уничтожается. Содержимое не записывается в localStorage/IndexedDB и не отправляется в сторонние просмотрщики.
- PDF.js и его worker, шрифты, CMaps и WASM обслуживаются самим приложением. `postinstall` готовит ресурсы в `/pdfjs/<версия>/`. Требуется Node.js 22.13+.

## Проверка

`npm run test:files-preview` собирает web и проверяет изображения, двухстраничный PDF, увеличение, поворот, переключение вложений, закрытие и возврат фокуса, освобождение ресурсов, повреждённый PDF, отказ в доступе и неподдерживаемый формат. Все документы синтетические, API перехватывается; рабочая база не используется.

Ручная проверка в MAX на телефоне: открыть «Приложения к договору», нажать на файл, увеличить/повернуть, перейти к следующему файлу или странице PDF, закрыть окно и скачать оригинал. Отдельно проверить сценарий внутри окна загрузки материалов и административной проверки. Chromium на мобильной ширине не заменяет проверку физического iPhone.
