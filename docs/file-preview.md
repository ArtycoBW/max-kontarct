# Предпросмотр файлов

Единый просмотрщик используется в приложениях договора, обязательных документах, материалах и доказательствах, ручной проверке администратора и для подписанного PDF. Окно и кнопки — общие компоненты shadcn/ui проекта.

- JPEG, PNG, WebP: масштаб, сброс масштаба, поворот и прокрутка увеличенного изображения.
- PDF: постраничное отображение, предыдущая/следующая страница и переход к выбранному номеру, масштаб по ширине, показ страницы целиком и поворот. Для одностраничного PDF панель переключения страниц не показывается. Отображается одна страница за раз, размер canvas ограничен для снижения расхода памяти.
- Список вложений: выбор файла по названию в заголовке окна, тип и размер, отдельное скачивание оригинала. Дополнительной нижней панели переключения файлов нет.
- Неподдерживаемый, повреждённый или защищённый паролем файл: объяснение и скачивание. При сетевой ошибке доступна повторная попытка.
- Доступ проверяет существующий серверный endpoint. Ошибки 401/403/404 не подменяются успешным просмотром. Личные документы не попадают в общий список договора.
- Содержимое загружается только после открытия, с credentials и cache:no-store. Изображения используют временные blob URL, которые освобождаются при закрытии/смене файла. Запросы отменяются, PDF worker уничтожается. Содержимое не записывается в localStorage/IndexedDB и не отправляется в сторонние просмотрщики.
- PDF.js и его worker, шрифты, CMaps и WASM обслуживаются самим приложением. `postinstall` готовит ресурсы в `/pdfjs/<версия>/`. Требуется Node.js 22.13+.

## Проверка

`npm run test:files-preview` собирает web и проверяет изображения, двухстраничный PDF, увеличение, поворот, переключение вложений, закрытие и возврат фокуса, освобождение ресурсов, повреждённый PDF, отказ в доступе и неподдерживаемый формат. Проверяются также карточки разделов сделки, согласование в окне договора, вложенный просмотр приложения, сохранение черновика сообщения при закрытии чата и возврат из документов в исходную сделку. Ширины экрана: 320, 390 и 1440 px. Все документы синтетические, API перехватывается; рабочая база не используется.

## Разделы сделки

Договор, приложения и чат открываются отдельными карточками. В договоре один прокручиваемый текст и отдельная панель согласования/редактирования; доступность действий по роли и статусу не меняется. Приложения не содержат личных документов. Скачивание общих приложений доступно в предпросмотре, в списке нет дублирующих кнопок. В окне приложений нет перехода «Документы сделки»: он остаётся на основном экране сделки. На телефоне просмотрщик занимает доступный экран. Несохранённый текст и тип сообщения сохраняются при закрытии окна чата в пределах открытой сделки.

При переходе «Документы сделки» из сделки кнопка «Назад» возвращает в неё. Если документы выбраны из общего раздела «Документы», возврат ведёт в список выбора сделки.

Ручная проверка в MAX на телефоне: открыть «Приложения к договору», нажать на файл, увеличить/повернуть, перейти к следующему файлу или странице PDF, закрыть окно и скачать оригинал. Отдельно проверить сценарий внутри окна загрузки материалов и административной проверки. Chromium на мобильной ширине не заменяет проверку физического iPhone.
