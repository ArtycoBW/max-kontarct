# Безопасность и границы текущей проверки

MAX initData проверяется по HMAC, времени и защите от повторного использования. Сессия HttpOnly, в production Secure/SameSite=None для WebView. Авторизация и роль проверяются сервером; UI не выдаёт административные права.

Запросы изменения данных с посторонним Origin отклоняются до обработчика, включая простые HTML-формы с файлами: одного CORS для этого недостаточно. Статусные сообщения MAX отправляются только при действующем согласии; запрошенный самим пользователем код подписи не зависит от необязательных уведомлений.

Приглашение: случайный секрет в URL fragment, в базе только SHA-256, ограниченный срок, отзыв, однократное атомарное присоединение. Публичный просмотр — whitelist полей без адресов, телефонов, реквизитов. Обязательны согласия на обработку данных и условия сервиса; статусные уведомления необязательны.

Файлы: лимит 20 МиБ, проверка MIME и сигнатуры, случайный приватный ключ. Каждый download проходит ACL. Документы личности доступны владельцу и уполномоченному администратору, но не второй стороне и не в общем ZIP. Антивирус/песочница и автоматическая проверка личности не заявляются реализованными.

Согласование открывается только после принятия обязательных документов обеих сторон. Подпись связана с неизменяемой версией/хешем. OTP хранится как HMAC, имеет срок, лимит попыток и отправок; старый код не подходит новой версии. Подписанные артефакты неизменяемы. Публичная проверка сравнивает байты PDF с сохранённым хешем и не выдаёт файл или данные сторон.

В прикладные логи не включаются query string, request/response body, cookies, токены, OTP и сторонние тексты ошибок. Для диагностики остаются requestId, маршрут, код/класс ошибки и HTTP-статус. Audit внутри защищённой базы отдельно содержит необходимые сведения об операциях; не публиковать его целиком. Nginx следует использовать формат лога без query string; инфраструктурные логи также ограничивать по доступу и сроку хранения.

## Матрица regression

| Проверка | Где закреплена |
| --- | --- |
| Неверный/просроченный/replay MAX, unauth | auth.e2e-spec, browser/security |
| Чужая существующая сделка и файл | browser/deal-lifecycle, files.service.spec |
| Перебор/отзыв/истечение приглашения | browser/security, deal-invitations.service.spec |
| Перебор/истечение OTP, другая версия | otp.service.spec, signing.service.spec |
| XSS и длинный пользовательский текст | browser/deal-lifecycle (комментарий администратора) |
| MIME spoof/размер/кириллица | file-validation.spec, files.spec Web |
| Отсутствие PII в логировании | logger.config.spec и review мест логирования |
| Публичные whitelist | deal-invitations.service.spec, deal-artifacts.service.spec, browser/deal-lifecycle |

Это функциональная security regression, не независимый пентест. Перед передачей сменить ранее пересланные пароли, перейти на SSH-ключи, ограничить root-вход, настроить внешний мониторинг и подтвердить юридические документы/сроки хранения. Оставшиеся действия хранятся в `CLIENT_HANDOFF_REMAINING.md`.
