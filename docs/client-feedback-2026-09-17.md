# Уточнения клиента — 17 сентября 2026

## Стартовая страница

Возвращены прежние фотофоны, цветовая гамма и светлые накладывающиеся карточки. Четыре этапа расположены вертикально в обычном потоке документа. Нет цифр, переключателя, смены текста, счётчика и шкалы просмотра. Единственный призыв к действию расположен после последнего этапа. Использованы существующие компоненты Card и Button; новая библиотека не добавлялась.

## Вставка реквизитов

Клиент уточнил, что речь о кнопке «Скопировать данные» в паспорте Цифрового ID, показанной в его видео, а не о ручной подготовке текста по шаблону. Также предоставлена структура скопированного текста Госуслуг.

- Поддержаны объединённые ФИО и серия/номер, подписи с двоеточиями, табуляцией или отдельной строкой, многострочные орган выдачи и адрес.
- Даты нормализуются и проверяются; код подразделения приводится к формату 000-000, пол — М/Ж. Числовые реквизиты не дополняются догадками.
- Совпадающие нормализованные повторы допустимы; конфликтующие и некорректные поля исключаются из переноса и перечисляются в подсказке.
- До переноса показываются найденные значения. Чтения буфера без действия пользователя, запросов к API и автоматического сохранения нет. Текст очищается при закрытии диалога.
- В образце Госуслуг доступны 11 полей профиля. Адрес отсутствует, поэтому не выводится и не подставляется.
- Настоящие реквизиты клиента и кадры его видео не добавлялись в проект или фикстуры. Для тестов использованы только вымышленные значения с аналогичной структурой.

### Границы проверки Цифрового ID

На предоставленном видео видна кнопка копирования, но не содержимое буфера. Поиск публичного примера точного результата копирования не дал проверяемого образца. Поэтому варианты с переносами строк проверены синтетическими тестами; совместимость с фактическим текстом из приложения MAX пока не подтверждена.

Открытая [справка MAX](https://dev.max.ru/help/digital-id) описывает отдельное подключение API Цифрового ID для бизнеса и сценарий гостиниц, но не спецификацию текста буфера обмена. Текстовый импорт в этом приложении не является такой интеграцией и не даёт отметку о проверке личности.

## Проверки

- 9 изолированных Chromium UI-тестов: начало работы, импорт/предпросмотр и регрессия согласий на ширине 320/390/1440. API и MAX подменены локальными ответами; реальные профили не изменялись.

- Реальный буфер Цифрового ID и целевой iPhone/MAX требуют отдельной проверки. Выкладка этой правки на сервер не выполнялась.
