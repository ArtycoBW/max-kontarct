# Mercury - Style Reference

Source: https://styles.refero.design/style/3172cd4d-118a-4a16-a259-6b634d32322e

## Direction

Dark private-banking workspace. The UI is quiet and exact: graphite panels sit directly on an onyx canvas, hierarchy comes from spacing and measured type, and cobalt is reserved for the single primary action.

## Tokens

- Canvas: `#171721`
- Card: `#1e1e2a`
- Secondary surface: `#272735`
- Border: `#70707d`
- Muted text: `#c3c3cc`
- Primary text: `#ededf3`
- Primary action: `#5266eb`
- Cards: `12px`
- Inputs and buttons: `32px`
- Navigation: floating graphite dock
- Shadows: none

## Product rules

- One cobalt action per screen.
- Use flat tonal separation, not glass blur or decorative gradients.
- Keep headings calm and medium-weight; no display gimmicks.
- Status and navigation icons use a dedicated geometric SVG family.
- Motion traces paths, state changes and progress; it never floats decorative cards.
